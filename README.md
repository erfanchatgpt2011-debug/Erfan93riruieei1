# Neon SMS Simulator

Android app with a black/neon-green interface that simulates SMS activity locally. It does **not** send real SMS messages.

## Build APK with GitHub Actions
1. Upload the contents of this project into the root of a GitHub repository, preserving folders.
2. Open **Actions** and run **Build Neon SMS Simulator APK**.
3. Download the `NeonSMS-debug-apk` artifact from the successful run. Extract it to get `app-debug.apk`.
